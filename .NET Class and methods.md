1. What is the .NET Class Library?
   - The .NET Class Library is a collection of thousands of classes containing tens of thousands of methods. For example, the
      .NET Class Library includes the Console class for developers working on console applications. The Console class includes
      methods for input and output operations such as Write(), WriteLine(), Read(), ReadLine(), and many others.
      ``` Console.WriteLine("Hello, World!")  ```

2. Creating an instance of a class:  
 - An instance of a class is called as an object. To create a new instance of a class, you use the new operator. Consider the      following line of code that creates a new instance of the Random class to create a new object called dice,  
 
 ```  ClassName.MethodName() ```
 
 -  . symbol is the **member access operator** to access a method defined on the class, and the () symbols are the **method invocation operators**.
 
 ``` Random dice = new Random();```

3. The new operator does several important things:

 - It first requests an address in the computer's memory large enough to store a new object based on the Random class.
 - It creates the new object, and stores it at the memory address.
 - It returns the memory address so that it can be saved in the dice object.
 new way ``` Random dice = new(); ```

 4. **There are 2 type of method in classes, stateful and stateless methods.**
 5. **Stateless Method (No Memory)**  
     - A stateless method is like a basic calculator. It does not remember your past calculations. It only cares about the            information you give it right now. If you give it the same inputs, it will always give you the exact same answer.  
     - How it behaves: It does its job, finishes, and instantly forgets everything.  
     - Real-world analogy: A vending machine. You put money in, press a button, get a soda, and the machine forgets who you         are.  
     - In.NET: These are usually static methods.
     ```
              public class Calculator
         {
             // This is stateless. It just adds the two numbers you give it.
             public static int AddNumbers(int a, int b)
             {
                 return a + b; 
             }
         }
     ```

6. **Stateful Method (Has Memory)**  
- A stateful method is like a bank account. It depends on a stored memory (called a "state") to do its job. The outcome of     the method changes depending on what happened before.  
- How it behaves: It reads or changes information stored outside of itself (like a class variable).  
- Real-world analogy: An online shopping cart. It remembers what you added 10 minutes ago.  
- In .NET: These are usually standard instance methods that rely on class fields.
``` 
   public class BankAccount
   {
       // This is the "state" (the memory)
       private int _balance = 100; 
   
       // This is stateful. The result changes based on the current balance.
       public void Withdraw(int amount)
       {
           _balance = _balance - amount; 
           Console.WriteLine($"Remaining balance: {_balance}");
       }
   }

```
   In short:-  
   - Stateless = Inputs in ➡️ Output out ➡️ Forgets everything.  
   - Stateful = Reads memory ➡️ Changes memory ➡️ Remembers for next time.

7.  **The Golden Rule:**  
- If a method reads or writes to class-level variables, it is Stateful. If it only uses data passed into its parameters (parameters) and variables created inside the method, it is Stateless.  

8. Return values and parameters of methods:-
   - Some methods don't return a value when they finish. They are referred to as void methods.
   - When calling a method that returns a value, you'll often assign the return value to a variable. That way, you can use         the value later in your code. In the dice scenario, you assigned the return value of Random.Next() to the roll               variable: ``` int roll = dice.Next(1, 7); ```  
   
**NOTE**:- Oftentimes, the terms 'parameter' and 'argument' are used interchangeably. However, 'parameter' refers to the variable that's being used inside the method. An 'argument' is the value that's passed when the method is called.  

9. Classes in .NET:-
- In your inserted line of code, Console.WriteLine() is calling, or running, the method WriteLine(). The method WriteLine()     is contained in the class Console.

   Where is this code? It's in the base class library. Actually, its full name is System.Console.WriteLine(). The opening       line in the preceding code example is: ``` using System; ```  
   The word System is omitted in your call to Console.WriteLine(). But the line using System; tells the C# compiler to look      in the base class library if it can't find the method definition in your code.
